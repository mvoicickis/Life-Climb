Camp view — collapsed composer

360px click-through. Full-screen camp page with camp fire behind the list. Back crumb, title, battle rows, kebab, close, and a composer that starts collapsed as “+ Add battle”.

How to use

  • Tap + Add battle to expand the composer. The input focuses automatically.
  • Type a battle, then tap the green + or press Enter to save. Focus stays for the next one.
  • Tap away with an empty input to collapse back to one row.
  • Tick an open battle row to mark it won. Won battles fold under Won today.
