Camp page — redesign

Four states in one file. CSS only, no images. Add row always at the bottom. Press Enter to save and keep typing. Tap a battle name to edit it.

Rules

  • No “0 battles ready here” — an empty list is enough.
  • Add row stays visible in every state.
  • Enter saves a battle and keeps focus in the add row.
  • Tap battle text to edit in place.
  • Won battles sit in a folded section — grey and crossed out.
  • Copy must be simple enough for an 8-year-old.
