Stats page mockup

Redesign of life_points/progress.html.erb (formerly “Journey”). Standalone HTML only — no Rails. 375 px mobile frame, Nunito, light app palette.

Dropped from the current page (and why)

  • Decorative mountain SVG hero art — replaced by a denser goal bar + inline expedition stats so charts get more room above the fold.
  • Standalone “Your strength” points section — AP and Planning points folded into the hero footer and Activity KPIs to avoid repeating the same numbers three times.
  • Separate Mountain Summary card — plans/camps counts and “Open Mountain” link merged into the hero; per-camp detail lives in expandable folders below.
  • Standalone Insights card — reframed as “What changed” at the top of the analytics stack (same detector copy, clearer scan pattern).
  • KPI sparklines without axes — replaced by labelled grid charts in Activity; deltas kept as text on KPI tiles.
  • Heatmap inside a collapsed <details> — heatmap is a retained feature, so it stays visible in the scroll (not buried).
  • Habit tracker reorder / add-tracker dialog — CRUD interactions omitted from this static mockup; read-only habit strips kept.
  • Condition-name labels (e.g. Non-Existence / Danger / Affluence) — excluded per product rule; no shipped defaults.
